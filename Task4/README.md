# 📝 Todo Master

A modern productivity Todo Web Application built using HTML, CSS and JavaScript.

## Features

✅ Add Tasks  
✅ Edit Tasks  
✅ Delete Tasks  
✅ Complete Tasks  
✅ Task Priority  
✅ Deadline Date & Time  
✅ Search  
✅ Filters  
✅ Dark Mode  
✅ Local Storage  
✅ Responsive UI  


## Technologies

- HTML5
- CSS3
- JavaScript


## How To Run

Open:

index.html

in any browser.
