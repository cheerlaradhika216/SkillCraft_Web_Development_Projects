# 🧠 QuizMaster

QuizMaster is a modern interactive quiz web application built with HTML, CSS, and JavaScript.

## 🚀 Features

- User login system
- Multiple quiz categories
- Easy, Medium, Hard difficulty levels
- Countdown timer
- AI hint system
- 50/50 lifeline
- Score calculation
- Leaderboard
- Sound effects
- Responsive glassmorphism UI

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

## 📂 Project Structure

QuizMaster/
│
├── index.html
├── style.css
├── script.js
└── assets/

## ▶️ How to Run

1. Download the project
2. Open `index.html` in a browser
3. Start playing
