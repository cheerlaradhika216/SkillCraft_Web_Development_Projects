Task 02 – Calculator Web Application

A fully functional web-based calculator developed using HTML, CSS, and JavaScript. This project emphasizes core front-end development concepts, including DOM manipulation, event handling, input parsing, and basic arithmetic operations.

📌 Task Description

Develop a functional calculator to strengthen skills in:

DOM manipulation

Event handling

Basic arithmetic operations

Input parsing

Button event listeners

Keyboard input handling

🛠️ Technologies Used

HTML5

CSS3

JavaScript

✨ Features

Supports addition, subtraction, multiplication, and division

Interactive and user-friendly calculator interface

Clear and delete functionality

Keyboard input support

Real-time display updates

Efficient event handling using JavaScript

Responsive design for multiple screen sizes

📂 Project Structure

Task-02/
│
├── index.html

🚀 How to Run

Clone or download the repository.

Navigate to the project directory.

Open index.html in any modern web browser.

Use either the on-screen buttons or keyboard input to perform calculations.

🎯 Objective

The objective of this task is to build a functional calculator while gaining hands-on experience with DOM manipulation, event handling, input processing, and JavaScript-based arithmetic operations.
