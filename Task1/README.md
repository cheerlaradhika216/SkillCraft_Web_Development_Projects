# Task 01 – Responsive Landing Page

A responsive landing page with an interactive navigation menu built using HTML, CSS, and JavaScript.

## 📌 Task Description

Create an interactive navigation menu that:

- Changes color or style when scrolling.
- Changes appearance when hovering over a menu item.
- Has a fixed position on the page.
- Remains visible while scrolling through the page.
- Works responsively across different screen sizes.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ✨ Features

- Responsive landing page design
- Fixed navigation bar
- Interactive hover effects
- Dynamic navigation style on scroll
- Smooth and user-friendly interface
- Mobile-friendly layout
